# Small-Stake Momentum Bot — Pump.fun Bot Sprint

A small-stake momentum trading bot for the [Pump.fun Bot Sprint](https://make.fun/bounty/u-riidzhsn-pump-fun-bot-sprint-make-bot-and-win-cb203fed): it trades 10 SOL of paper money on a 6h replay of recorded pump.fun bonding-curve activity, buying 0.02 SOL per curve only on tight momentum (rising price, broad-based net inflow, healthy curve) and exiting on an 8% stop loss, a 40% trailing stop, or a 5x take-profit.

Run with Node 22: `node main.ts` (the grader runs `node /bot/main.ts`).
